Tight Lines - Browser Play Instructions
======================================

Thank you for playing Tight Lines!

How to Play (Web Version)
-------------------------
1. Open the game page in a modern browser:
   - Chrome
   - Edge
   - Firefox
   - Safari

2. Click "Run game" on itch.io to start.

3. If audio is muted, click once inside the game window to enable browser audio playback.

4. Enjoy fishing!

Troubleshooting
---------------
- If the game does not load, hard refresh the page (Ctrl+F5 on Windows/Linux, Cmd+Shift+R on Mac).
- Disable strict ad/script blockers for the itch.io game page if assets fail to load.
- For best performance, close extra tabs and run in an up-to-date browser.

Controls
--------
- Mouse for menus and casting.
- Arrow keys or WASD during the minigame.

Feedback
--------
If you encounter any issues or have suggestions, please leave a comment on the game's itch.io page.
